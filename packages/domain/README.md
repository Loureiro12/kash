# @kash/domain

Regras de negócio puras do Kash (tipos, dinheiro, datas, seletores, virada de mês) sem dependência de React ou Supabase. Consumido pelo app mobile, pelos testes de integração do backend e, futuramente, pelas Edge Functions.

- `pnpm --filter @kash/domain test` — Vitest
- `pnpm --filter @kash/domain typecheck`
